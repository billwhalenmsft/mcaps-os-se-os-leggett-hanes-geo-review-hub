Cowork-first pattern

Cowork is where the work happens

The intended experience is conversational and document-centered: Cowork reviews the authorized source set, runs the bounded calculation, explains the evidence, and incorporates reviewer corrections. Dynamics receives only the final reviewed information as a read-only result.

Current validation boundary. This public prototype has not yet been executed in a native customer Cowork session. The sample results below come from a local deterministic run using public federal documents and synthetic geometry.
1

Bring the approved document set

Attach the authorized project documents, the bounded task, and the deterministic calculation package to a Cowork session. For this public sample, the sources are USDA NRCS and USACE specifications.

2

Review, calculate, and correct in Cowork

Cowork can keep the source files, task progress, questions, output files, and revisions together. Reviewers can ask why a value was proposed, correct an input, and rerun the calculation before approval.

3

Hand off the final result

After human review, the finalized values and evidence summary can be presented in Dynamics 365 without editing controls. Cowork remains the place to revisit documents or make a new revision.

What is established: Microsoft Learn documents Cowork file attachments, progress updates, background script execution, output files, and in-session previews. Read the official Cowork guidance. This page does not claim that the Leggett & Platt tenant path, permissions, or final Dynamics integration have been completed.
